## 使用建议（重要）

1. **严格按顺序走主线**  
   不要跳着学。基础句子没过关就直接上从句和虚拟，效率会很低。

2. **`.1` 易错点紧跟主篇**  
   学完主文后马上看易错点，趁热打铁。

3. **每篇学完立刻输出**  
   用自己的生活、工作、学习场景造 2–3 个真实句子，比默读有效十倍。

4. **把工具型笔记常备**  
   - `13_思维与阅读提问体系` → 读任何材料时用  
   - `21_连接词与过渡词` + `24_写作段落结构` → 写段落时用  
   - `23_中式英语常见错误` → 写完自己检查时用

5. **时态不要死记表格**  
   重点理解「时间 + 状态」的组合逻辑，先把高频时态用熟。

## 自检清单（学完每个阶段后可对照）

**阶段一结束时：**
- [ ] 能区分四种句子用途
- [ ] 能写出完整的陈述句和疑问句
- [ ] 时间/地点/方式状语位置基本正确

**阶段二结束时：**
- [ ] 能解释「从句是什么」
- [ ] 核心时态（现在、过去、完成、将来）能正确使用
- [ ] 能识别句子中的非谓语

**阶段三结束时：**
- [ ] 冠词和介词错误明显减少
- [ ] 能用提问体系主动分析句子

**阶段四结束时：**
- [ ] 能写出带连接词的连贯段落
- [ ] 能自己发现并修正中式英语

**阶段五结束时：**
- [ ] 能分析定语从句、状语从句、名词性从句
- [ ] 对虚拟、倒装、强调不再完全陌生
