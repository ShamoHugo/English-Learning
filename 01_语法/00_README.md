## 二、 使用建议

1. **按顺序走主线，`.1` 易错点紧跟主篇**
  读完主篇（如 `25_定语从句专项.md`）后立刻阅读对应的 `25.1_定语从句易错点汇总.md`，趁热打铁对比常见误区，效果远好于最后统一刷一遍。
2. **时态与句型重在“理解逻辑”而非“死记表格”**
  阅读 `08_英语16种时态.md` 时重点看不同时间与状态组合背后的表达意图（先抓高频核心时态，生僻组合先混个眼熟）；遇到 `06_如何写出一个完整的句子.md` 和 `23_中式英语常见错误.md` 时，多对照自己平时容易写出的中式句式。
3. **每学完一篇，立刻写 2～3 个真实例句**
  学完语序、从句、条件句或比较结构后，用自己的日常、工作或学习场景造句，比单纯默读笔记更容易形成肌肉记忆。
4. **把思维与结构类笔记当作“工具箱”常翻**
  `13_思维与阅读提问体系.md`、`21_连接词与过渡词.md`、`24_写作段落结构.md` 偏思维与输出方法，在读长难句、写段落或梳理逻辑时随时回头查阅，能帮你把零散语法串成完整句子和段落。
5. **后续微调顺序时，同步维护本目录**
  如果之后继续调整编号或新增 `xx.1` 补充笔记，建议顺手更新本 `README.md` 的文件链接，保持目录与仓库状态一致。
