# 条件句（Conditionals）

> 条件句是表达「如果……就会……」的重要结构，也是写作和口语中的高频语法点。

---

## 一、四种基本条件句

### 1. 零条件句（Zero Conditional）
**用法**：表示客观真理、科学事实、习惯性结果。

**结构**：
If + 一般现在时，一般现在时

例句：
- If you heat water to 100°C, it boils.
- If I am tired, I go to bed early.

---

### 2. 第一条件句（First Conditional）
**用法**：表示真实的、可能发生的将来情况。

**结构**：
If + 一般现在时，will + 动词原形

例句：
- If it rains tomorrow, we will stay at home.
- If you study hard, you will pass the exam.

**变体**：
- If + 一般现在时，can / may / might / should + 动词原形
- If + 一般现在时，祈使句

---

### 3. 第二条件句（Second Conditional）
**用法**：表示现在或将来不太可能实现的假设、虚拟情况。

**结构**：
If + 一般过去时，would + 动词原形

注意：be 动词在正式场合常用 were（适用于所有人称）

例句：
- If I had more time, I would learn another language.
- If I were you, I would accept the offer.
- If she knew the truth, she would be very angry.

---

### 4. 第三条件句（Third Conditional）
**用法**：表示对过去已经发生事情的虚拟假设（与过去事实相反）。

**结构**：
If + 过去完成时，would have + 过去分词

例句：
- If I had studied harder, I would have passed the exam.
- If she had left earlier, she would have caught the train.
- If they had told me, I would have helped them.

---

## 二、混合条件句（Mixed Conditionals）

有时条件与结果的时间不一致。

### 1. 过去条件 + 现在结果
If + 过去完成时，would + 动词原形

- If I had taken that job, I would be rich now.
- If she had studied medicine, she would be a doctor now.

### 2. 现在条件 + 过去结果
If + 一般过去时，would have + 过去分词

- If I were more careful, I wouldn't have made that mistake.
- If he were taller, he would have become a basketball player.

---

## 三、其他常用结构

| 结构 | 含义 | 例句 |
|------|------|------|
| unless | 除非（= if not） | Unless you hurry, you will be late. |
| as long as | 只要 | As long as you finish on time, it's fine. |
| provided (that) | 如果、只要 | Provided that it doesn't rain, we will go. |
| on condition that | 条件是 | I'll help you on condition that you try hard. |
| in case | 以防 | Take an umbrella in case it rains. |
| even if | 即使 | Even if it rains, we will go. |

---

## 四、常见错误

| 错误 | 正确 | 说明 |
|------|------|------|
| If it will rain, we will stay home. | If it rains, we will stay home. | if 从句通常不用 will |
| If I am you, I would go. | If I were you, I would go. | 虚拟语气用 were |
| If I would have known, I would have told you. | If I had known, I would have told you. | if 从句用过去完成时 |
| If he studied harder, he will pass. | If he studied harder, he would pass. | 第二条件句主句用 would |

---

## 五、快速记忆表

| 类型 | if 从句 | 主句 | 时间/真实性 |
|------|---------|------|-------------|
| 零条件 | 一般现在时 | 一般现在时 | 真理、习惯 |
| 第一条件 | 一般现在时 | will + V | 真实可能的将来 |
| 第二条件 | 一般过去时 | would + V | 现在/将来虚拟 |
| 第三条件 | 过去完成时 | would have + V-ed | 过去虚拟 |
